द्विघात समीकरण कैलकुलेटर

समीकरण ax² + bx + c = 0 के लिए a, b और c के मान डालें और मूल और विविक्तकर पाएं।

गुणांक डालें

द्विघात समीकरण कैसे हल होता है?

हम द्विघात सूत्र इस्तेमाल करते हैं: x = (−b ± √(b² − 4ac)) ÷ 2a। विविक्तकर Δ = b² − 4ac विविक्तकर मूलों का प्रकार बताता है: धनात्मक = दो वास्तविक मूल, शून्य = एक दोहराया मूल, ऋणात्मक = कोई वास्तविक मूल नहीं। उदाहरण: x² − 5x + 6 = 0 देता है x = 2 और x = 3।
